# Internationalization (next-intl)

## Locales

| Code | URL | Status |
|------|-----|--------|
| `en` | `/about` (default, no prefix) | Active |
| `fr` | `/fr/about` | Active |
| `ar` | `/ar/about` | Active (RTL) |

Admin (`/admin/*`), member (`/member/*`), and API routes are **not** localized.

### Member & admin dashboards

Dashboard UIs use **fixed English copy in components** — not `messages/*.json` and not the CMS.

| Area | Routes | Copy source |
|------|--------|-------------|
| Member portal | `/member/*` | Hardcoded in `apps/frontend/src/app/member/` and `member-shell.tsx` |
| Admin panel | `/admin/*` | Hardcoded in `apps/frontend/src/app/admin/` and `admin-shell.tsx` |
| Auth screens | `/member/login`, `/admin/login`, etc. | Hardcoded in `apps/frontend/src/app/(auth)/` |

Do **not** add `useTranslations` / `getTranslations` to these routes. There is no language switcher on dashboards. Only the **public marketing site** under `/[locale]/` is translated (EN / FR / AR).

The `forms` keys in `messages/{locale}/content.json` are for **public** contact, summit, and engagement forms — not member or admin screens.

## Adding copy

1. Add keys to `apps/frontend/messages/en.json`
2. Mirror in `apps/frontend/messages/fr.json`
3. Use in components:
   - Server: `getTranslations('namespace')` from `next-intl/server`
   - Client: `useTranslations('namespace')` from `next-intl`

## Links

Use `Link` from `@/i18n/navigation` (not `next/link`) so locale prefixes are applied.

## Media folders for press/summit pages

| Folder | Used on |
|--------|---------|
| `summit` | `/summit/media` |
| `press` | `/insights/media` |
| `heroes` | Homepage hero |

Upload matching assets in **Admin → Media** with the folder name.

## Detail page content

Long-form copy is in `apps/frontend/messages/{locale}/content.json`, merged in `src/i18n/request.ts`.

## Arabic (RTL)

Locale `ar` sets `dir="rtl"` on `<html>` via `LocaleAttributes`. Shell strings: `messages/ar.json`. Detail copy: `messages/ar/content.json` (expand native Arabic over time).
